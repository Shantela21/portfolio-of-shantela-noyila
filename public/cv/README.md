# CV Folder

Place your CV PDF file here with the name: **Shantela_Noyila_CV.pdf**

The download button in your portfolio will link to this file.

## Instructions:
1. Export or save your CV as a PDF file
2. Rename it to: `Shantela_Noyila_CV.pdf`
3. Place it in this folder (`public/cv/`)
4. The file will be automatically accessible at `/cv/Shantela_Noyila_CV.pdf`
